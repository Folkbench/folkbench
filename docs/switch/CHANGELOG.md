# Folkbench Switch 更新记录

## 0.1.0-beta.1 — 准备中，尚未公开发布

- 客户端源码迁入 Folkbench 公开仓库，博客与桌面端独立构建。
- 设置页展示 Beta 版本和构建提交，版本文件由统一脚本管理。
- OpenCode 按所选协议写入对应 SDK；客户端加入单实例与共享配置写入锁。
- 配置操作失败只恢复本次写入；检测外部改动时停止，避免覆盖其他工具的配置。
- 准备 macOS / Windows 候选构建、平台验证、签名公证和人工审批发布流程。

尚未解决的发布阻断项见 `apps/switch/release-policy.json`。本记录不代表安装包或签名已经发布。
