# Folkbench editorial desk design

This repository uses the visual DNA in [`design/folkbench-blog-dna.json`](./design/folkbench-blog-dna.json) for article typography and evidence surfaces. It is content-only: the Folkbench main site owns the `/blog/[slug]` route, article list decisions, Header, Footer, and navigation shell.

Article surfaces use the Folkbench neutral page surface, near-black actions, cool keylines, evidence colors, and restrained motion. Header/Footer styles are intentionally not duplicated here because the main site owns them. No ModelFlare asset, logo, author name, copy, metric, customer story, or private implementation is included.

Editorial personas are fictional roles. The article manifest is a list of published editorial pages, not a measurement database. A measured result must come from a published Folkbench run and release snapshot.
