Folkbench Kimi K3.1 Pro article illustrations

Illustrations follow the existing Folkbench monochrome icon registry and
editorial design. Charts are redrawn from the official comparison at:
https://www.kimi.com/en/blog/kimi-k3-1-pro
Checked: 2026-10-23. These are not measurements performed by Folkbench.
Terminal-Bench 4.0: Kimi K3.1 Pro 65.7, Claude Opus 5.5 66.4, GPT-6 Astra 58.2.
BenchCAD with tools (Voxel IoU): 92.7, 96.2, 95.9, in the same model order.
Scales start at zero; different metrics are never averaged.

Kimi mark: existing LobeHub icon distributed in the Folkbench UI package.
Outline icons: existing Lucide registry used by the Folkbench UI package.
