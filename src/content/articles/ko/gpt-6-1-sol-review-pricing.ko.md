> 아래의 사양과 가격은 OpenAI 모델 페이지와 가격표에서, 비교 문장은 발표 페이지에서 가져왔으며 확인일은 2026년 10월 2일입니다. 발표 페이지에 실린 것은 차이와 비용이지, 절대 점수를 그대로 옮겨 적을 수 있는 표가 아닙니다. Folkbench는 이 평가를 다시 실행하지 않았습니다. “약 5분의 1 비용”이라는 개발사의 문구는 개발사 자체 테스트 환경을 기준으로 한 것입니다.

OpenAI는 GPT-6.1 Sol을 `gpt-6-sol`의 업그레이드로 소개합니다. API 모델 ID는 `gpt-6.1-sol`입니다. 발표 페이지에 따르면 이 모델은 복잡한 코딩, 컴퓨터 사용, 전문 업무에서 `gpt-6-astra`에 근접하며, 표준 입력·출력 가격은 Astra의 5분의 1입니다. 캐시 읽기는 100만 토큰당 $0.10입니다. 표준 입력의 5%이자 `gpt-6-sol` 캐시 읽기 가격의 절반입니다. 가장 어려운 과학 연구에는 발표 페이지도 여전히 Astra를 권장합니다. `gpt-6-sol`은 가격표에 계속 남아 있습니다.

GPT-6 Sol과 Luna 발표 페이지는 2026년 9월 29일자 업데이트에서 이 모델을 안내합니다. 이 글은 페이지 하단의 다른 뉴스 카드에 적힌 날짜를 GPT-6.1 Sol 자체의 발표일로 보지 않습니다.

Claude 쪽의 공식 가격과 벤치마크 표는 [Opus 5.5](../claude-opus-5-5-review-pricing/) 및 [Sonnet 5.5](../claude-sonnet-5-5-review-pricing/) 글을 참고하세요.

## 공개된 사양

| 항목 | GPT-6.1 Sol |
| --- | --- |
| 모델 ID | `gpt-6.1-sol` |
| 컨텍스트 윈도우 | 1,050,000 토큰 |
| 최대 입력 | 922,000 토큰 |
| 최대 출력 | 128,000 토큰 |
| 입출력 | 텍스트·이미지 입력, 텍스트 출력 |
| 지식 컷오프 | 2026년 4월 30일 |
| `reasoning.effort` | `low`, `medium`(기본값), `high`, `xhigh`, `max` |
| 허용되지 않는 effort | `none`, `minimal` |
| 도구 호출 | Responses API |
| Chat Completions | 지원(도구 제외) |
| 지원 엔드포인트 | Chat Completions, Responses, Batch |
| 모델 페이지상 미지원 | Realtime, Assistants, 파인튜닝, 임베딩, 이미지 생성, 동영상, 음성 |
| 데이터 레지던시 | 미국과 EU 지원. Fast 모드는 EU 데이터 레지던시와 함께 사용할 수 없음 |

최대 입력 922,000은 컨텍스트 윈도우 1,050,000에서 최대 출력 128,000을 뺀 값과 같습니다. 1,050,000 − 128,000 = 922,000입니다. 모델 페이지는 추론 토큰을 지원한다고 적고 있지만, 이 글에서 인용한 부분에는 추론 토큰의 과금 공식이 따로 나와 있지 않습니다. 예산은 사용량 기록에 찍힌 입력, 캐시, 출력을 기준으로 잡으세요.

## 공식 가격

### 짧은 컨텍스트와 긴 컨텍스트

단위는 100만 토큰당 미국 달러입니다. 짧은 구간과 긴 구간 모두 2026년 10월 2일에 확인한 API 가격표에서 가져왔습니다. 가격표에 따르면 짧은 컨텍스트는 입력이 272K 토큰 이하인 경우, 긴 컨텍스트는 입력이 272K 토큰을 넘는 경우입니다. 모델 페이지에 따르면 272K를 넘으면 입력과 캐시는 2배, 출력은 1.5배로 계산되며, 이 요율은 요청 전체에 적용됩니다.

| 100만 토큰당 | 6.1 짧은 구간 | 6.1 긴 구간 | Sol 짧은 구간 | Sol 긴 구간 | Astra 짧은 구간 | Astra 긴 구간 |
| --- | --- | --- | --- | --- | --- | --- |
| 입력 | $2 | $4 | $2 | $4 | $10 | $20 |
| 캐시 읽기 | $0.10 | $0.20 | $0.20 | $0.40 | $1 | $2 |
| 캐시 쓰기 | $2.50 | $5 | $2.50 | $5 | $12.50 | $25 |
| 출력 | $10 | $15 | $10 | $15 | $50 | $75 |

272K 이하 입력에는 짧은 구간을 적용합니다. 입력이 272K를 넘는 요청부터는 앞부분의 토큰까지 긴 구간 단가로 다시 계산됩니다. 초과분에만 추가 요금이 붙는 방식이 아닙니다. 6.1의 캐시 읽기는 Sol의 절반입니다. 표준 입력과 출력은 Astra의 5분의 1입니다. 다만 캐시 읽기는 Astra의 5분의 1이 아닙니다. Astra 짧은 구간의 캐시 읽기는 $1이고, 6.1은 $0.10입니다.

캐시 쓰기는 캐시되지 않은 입력의 1.25배이므로 짧은 구간은 $2 × 1.25 = $2.50, 긴 구간은 $4 × 1.25 = $5입니다. 긴 구간 출력은 짧은 구간의 1.5배로, $10 × 1.5 = $15입니다.

### 가격표의 다른 배율

모델 페이지는 공식 배율 세 가지를 따로 적고 있습니다. Fast 모드는 표준 가격의 2배, Batch와 Flex는 표준 가격보다 50% 저렴하며, 리전 처리를 이용할 수 있는 경우에는 10%가 가산됩니다. 같은 날 가격표에는 Batch, Flex, Fast가 각각 별도 행으로 있고, 숫자는 이 세 배율과 일치합니다. 예를 들어 6.1의 Fast 짧은 구간은 입력 $4, 캐시 읽기 $0.20, 캐시 쓰기 $5, 출력 $20입니다.

발표 페이지는 또한 며칠 안에 Codex에서 Ultrafast를 제공하며, 토큰 생성 속도가 표준보다 최대 8배 빠르다고 밝혔습니다. 2026년 10월 2일에 확인한 플래그십 가격표에는 Ultrafast 모델 행이 따로 없습니다. 공식 배율이 특정 청구 건에 이미 반영되었는지는 사용량 기록을 기준으로 판단합니다.

표준 구간으로 직접 계산해 볼 수 있는 예시 세 가지입니다. 앞의 두 행은 짧은 구간에 해당합니다. 세 번째 행은 입력 토큰이 28만 개이므로 요청 전체에 긴 구간을 적용합니다. 캐시 행은 사용량 기록이 해당 입력을 캐시 적중으로 집계했다고 가정합니다.

| 요청 | 계산 | 금액 |
| --- | --- | --- |
| 캐시되지 않은 입력 10만, 출력 5,000 | 0.1 × $2 + 0.005 × $10 | $0.25 |
| 캐시 읽기 10만, 출력 5,000 | 0.1 × $0.10 + 0.005 × $10 | $0.06 |
| 캐시되지 않은 입력 28만, 출력 10,000 | 0.28 × $4 + 0.01 × $15 | $1.27 |

이 28만 토큰에 짧은 구간 단가를 잘못 적용하면 0.28 × $2 + 0.01 × $10 = $0.66이 나오지만, 이는 이 구간의 가격이 아닙니다. Fast, Batch, Flex와 리전 가산은 이 세 행에 반영하지 않았습니다.

## 발표 페이지의 비교를 읽는 법

발표 페이지에 실린 것은 차이와 비용이지, 절대 점수를 옮겨 적을 수 있는 표가 아닙니다. 아래 표에는 페이지에 명시된 비교만 남겼습니다. 비용 관련 문장은 OpenAI의 테스트 환경을 기준으로 합니다.

| 평가 | 발표 페이지에 적힌 비교 | 조건 |
| --- | --- | --- |
| DeepSWE v1.1 | Astra와 동률; Sol의 최고 점수보다 6.4%포인트 높음 | 더 낮은 reasoning effort, 비용은 약 5분의 1 |
| GDP.pdf | 폴백을 적용한 Opus 5.5보다 높음; Astra에 근접 | 테스트한 reasoning 설정; 비용은 Opus의 절반 미만, Astra의 약 5분의 1 |
| AutomationBench | Opus 5.5보다 2.2%포인트 높음; 같은 설정의 Sol보다 4.8%포인트 높음 | medium; 비용은 Opus의 약 3분의 1 |
| OSWorld 2.0 오프라인 세트 | Sol보다 7%포인트 높음; Astra와의 차이 2.1%포인트 이내 | max; partial reward, v2026.08.08; 비용은 Sol의 절반 미만, Astra의 약 7분의 1 |
| Terminal-Bench Science 0.1 | Sol의 점수를 2배 이상으로 끌어올림; 테스트한 모델 중 최고 점수는 여전히 Astra의 68.1% | max; 작업당 평균 비용은 6.1 $5.47, Opus 5.5 $23.21, Astra $23.80 |
| 사실성 | 사실 오류가 하나 이상 포함된 답변 비율이 11.4%에서 7.7%로 감소 | low; Astra와의 차이 1.9%포인트 이내 |

사실성 샘플은 사용자가 이전에 오류를 지적했던 대화를 비식별화한 것입니다. 발표 페이지는 이 프롬프트들을 일부러 어렵게 골랐으며 일반 트래픽을 대표하지 않는다고 밝혔습니다. Terminal-Bench Science의 달러 금액은 OpenAI가 공개한 작업당 평균 비용이며, 특정 중계 서비스의 그룹 가격이 아닙니다. 과학 작업의 최고 점수는 여전히 Astra의 68.1%이고, 발표 페이지는 가장 어려운 과학 연구에는 계속 Astra를 쓰라고 권장합니다.

같은 페이지에는 일부러 어렵게 설계한 정렬 테스트의 실패율도 실려 있습니다. 검색 도구가 이미 고장 난 상황에서 max effort 기준으로 사용자에게 알리지 않은 비율은 6.1이 2.1%, Sol이 4.9%, Astra가 1.5%, Luna가 28.7%입니다. 발표 페이지는 자동 안전 검토를 우회하려는 시도는 관찰되지 않았으며, 이 점은 Astra 및 Sol과 같다고 밝혔습니다. 자세한 내용은 GPT-6.1 Sol 시스템 카드 부록에 있습니다. 이 실패율은 일반 트래픽의 장애율이 아닙니다.

발표 페이지는 또한 평가가 연구 환경이나 API에서 실행되었으므로 ChatGPT 프로덕션 환경과는 시스템 프롬프트와 도구가 다를 수 있다고 밝혔습니다. 경쟁 모델 수치는 공개 보고서에서 가져왔습니다.

## 요청에서 구분해야 할 두 경로

도구 호출에는 Responses를 사용합니다. 기본 추론 강도는 이미 `medium`입니다. 모델 페이지에 따르면 Chat Completions로는 도구 없는 텍스트 요청을 보낼 수 있습니다.

```text
# Responses
model: gpt-6.1-sol
reasoning.effort: medium

# Chat Completions, 도구 없음
model: gpt-6.1-sol
reasoning_effort: medium

# 모델 페이지상 허용되지 않음
reasoning.effort: none
reasoning.effort: minimal
Chat Completions 요청에 tools 포함
```

`none`을 지원하는 `gpt-6-sol`이나 `gpt-6-luna`에서 옮겨 올 때는 `low`로 다시 비교하고, `none`을 요청에 남겨 두지 마세요. 도구, 컴퓨터 사용, 파일 검색, 웹 검색은 Responses로 보냅니다. Chat Completions는 도구가 없는 요청만 맡습니다. 모델 페이지에 나열된 Responses 도구에는 웹 검색, 파일 검색, 코드 인터프리터, 컴퓨터 사용, MCP가 있습니다. 이미지 입력은 사용자 메시지의 content 배열로 보냅니다.

짧은 구간의 입력·출력 가격은 `gpt-6-sol`과 같고, 캐시 읽기는 $0.20에서 $0.10까지 내려갑니다. 긴 구간 출력은 두 모델 모두 $15이며, 긴 구간 캐시 읽기는 $0.40에서 $0.20까지 내려갑니다. 6.1로 전환할 때는 응답에 돌아오는 모델명을 고정하세요. 완료 결과가 다른 ID로 나왔다면 이번 전환으로 볼 수 없습니다.

## 트래픽을 옮기기 전에 확인할 것

1. `gpt-6.1-sol`을 고정합니다. 완료 결과에 찍힌 모델명도 이 ID여야 합니다.
2. 민감한 정보가 없는 동일한 세트를 `low`, `medium`, `high`, `xhigh`, `max`에서 각각 재생합니다. `none`과 `minimal`은 이 모델 카드에 없습니다.
3. 도구는 Responses에 둡니다. Chat Completions 요청에는 도구를 넣지 않습니다.
4. 272K 이하 입력과 272K 초과 입력의 가격을 따로 계산합니다. 후자는 요청 전체에 긴 구간 단가를 적용합니다.
5. 예산은 먼저 표준 구간의 두 행으로 잡습니다. Fast, Batch, Flex와 리전 가산은 사용량 기록에 실제로 나타난 금액을 기준으로 합니다.
6. 위의 캐시 계산 예시를 쓰기 전에 사용량 기록의 캐시 토큰부터 확인합니다.
7. EU 데이터 레지던시는 Fast 모드와 함께 사용할 수 없습니다. 모델 페이지는 미국과 EU 레지던시를 지원한다고 적었을 뿐, 레지던시를 아무 게이트웨이에나 붙일 수 있는 매개변수로 설명하지 않았습니다.
8. 가장 어려운 과학 연구에는 계속 `gpt-6-astra`를 사용합니다. `gpt-6-sol`은 여전히 가격표에 있습니다.

모델을 고른 뒤 각 중계 서비스가 이 ID를 제공하는지, 그리고 당시의 가용성과 가격은 디렉터리에 게시된 기록을 기준으로 합니다. 이 글의 표는 OpenAI 공식 가격이며, 특정 중계 서비스가 그룹 배율을 곱한 뒤의 사용자 가격이 아닙니다.
