> 아래의 사양과 가격은 xAI 문서와 가격표에서, 벤치마크는 2026년 9월 21일 발표 페이지에서 가져왔으며 확인일은 2026년 10월 2일입니다. Folkbench는 이 평가를 다시 실행하지 않았습니다. 발표 페이지에 실린 경쟁 모델의 가격과 점수는 그 페이지에 인쇄된 숫자이며, 같은 날 OpenAI나 Anthropic 가격표와 다시 대조한 값이 아닙니다.

xAI는 2026년 9월 21일 Grok 4.7을 발표했습니다. API 모델명은 `grok-4.7`입니다. 문서는 이 모델을 코딩, 에이전트 작업, 지식 업무를 위한 프런티어 모델로 소개합니다. 발표 페이지 본문에는 [Grok 4.6](https://x.ai/news/grok-4-6)과 같은 가격, 같은 속도로 제공된다고 적혀 있습니다. 그런데 같은 페이지의 헤드라인에는 “약 2배 빠른 속도, 동급 모델의 약 절반 가격”이라고 적혀 있습니다. 두 문장 모두 발표 페이지에 실려 있지만, 이 글은 헤드라인 문구를 또 하나의 가격표로 계산하지 않습니다.

같은 날 서로 대조해 볼 수 있는 공개 페이지는 크게 세 곳입니다. 문서의 개요 표에는 500,000 토큰 컨텍스트 윈도우, 2026년 5월 지식 컷오프, 짧은 컨텍스트 기준 입력 $2와 출력 $6이 나와 있습니다. 가격표는 프롬프트가 200K 토큰에 도달하면 긴 컨텍스트 요율로 바뀌며, 이 요율은 요청 전체에 적용됩니다. 발표 페이지의 벤치마크 표는 `grok-4.7`을 Grok 4.6, GPT-5.6 Sol, Fable 5.1과 나란히 놓습니다. OpenAI 쪽의 긴 컨텍스트 요금 구간은 [GPT-6.1 Sol](https://folkbench.com/ko/blog/gpt-6-1-sol-review-pricing) 글을, Claude 쪽은 [Opus 5.5](https://folkbench.com/ko/blog/claude-opus-5-5-review-pricing) 및 [Sonnet 5.5](https://folkbench.com/ko/blog/claude-sonnet-5-5-review-pricing) 글을 참고하세요.

## 공개된 사양

| 항목 | Grok 4.7 |
| --- | --- |
| 모델명 | `grok-4.7` |
| 발표일 | 2026년 9월 21일 |
| 컨텍스트 윈도우 | 500,000 토큰 |
| 지식 컷오프 | 2026년 5월 |
| 입출력 | 텍스트·이미지 입력, 텍스트 출력 |
| 개요 표의 출력 한도 | 텍스트 출력 한도 없음으로 표기, 최대 출력 토큰 수는 따로 없음 |
| 추론 강도 | `low`, `medium`, `high`(기본값), `xhigh` |
| API | Responses, Chat Completions |
| 문서에 나열된 도구 | 함수 호출, 웹 검색, X 검색, 코드 실행 |
| 모델 페이지의 Batch API | 미지원 |

모델 페이지는 기본 추론 강도를 `high`로 적고 있습니다. 문서는 Responses API에서는 `prompt_cache_key`를, Chat Completions에서는 `x-grok-conv-id` 요청 헤더를 설정하라고 권장합니다. 페이지에 따르면 이 키가 없으면 대화 요청이 아직 캐시가 없는 서버로 가는 경우가 많고, 입력은 캐시되지 않은 가격으로 계산됩니다. Responses는 요청의 `include`에 넣지 않았더라도 `reasoning.encrypted_content`를 반환합니다. 멀티턴 대화에서는 이 reasoning 항목을 그대로 다음 요청의 `input`에 다시 넣어야 합니다. 문서에 따르면 Chat Completions는 이 부분이 바뀌지 않았습니다.

문서에 나열된 이용 경로는 xAI API, 미국 리전 엔드포인트 `https://us.api.x.ai/v1`, Grok Build, Cursor, 그리고 게이트웨이인 OpenRouter, Vercel, Cloudflare입니다. Grok Build의 기본 모델이 바로 이 모델입니다. 미국 리전 엔드포인트에 현재 적혀 있는 모델은 `grok-4.7`과 `grok-4.6`입니다. 특정 중계 서비스가 이 ID를 제공하는지는 디렉터리에 게시된 기록을 기준으로 합니다.

## 공식 가격

### 짧은 컨텍스트와 긴 컨텍스트

단위는 100만 토큰당 미국 달러입니다. 짧은 구간과 긴 구간 모두 2026년 10월 2일에 확인한 API 가격표에서 가져왔습니다. 가격표에 따르면 긴 컨텍스트의 기준은 프롬프트 200K 토큰이며, 일단 이 기준에 도달하면 해당 요청의 모든 토큰이 긴 구간 단가로 계산됩니다. 초과분에만 추가 요금이 붙는 방식이 아닙니다. 이 표에서 `grok-4.7`과 `grok-4.6`의 여섯 칸은 모두 같습니다.

| 100만 토큰당 | 4.7 짧은 구간 | 4.7 긴 구간 | 4.6 짧은 구간 | 4.6 긴 구간 |
| --- | --- | --- | --- | --- |
| 입력 | $2 | $4 | $2 | $4 |
| 캐시 읽기 | $0.50 | $1 | $0.50 | $1 |
| 출력 | $6 | $12 | $6 | $12 |

200K 미만 프롬프트에는 짧은 구간을 적용합니다. 200K에 도달하는 요청부터는 앞부분의 토큰까지 긴 구간 단가로 계산됩니다. 긴 구간은 짧은 구간의 2배입니다. $2 × 2 = $4, 캐시 $0.50 × 2 = $1, 출력 $6 × 2 = $12입니다. 캐시 읽기는 같은 구간 입력 가격의 4분의 1입니다. $2 × 0.25 = $0.50, $4 × 0.25 = $1입니다.

표준 구간으로 직접 계산해 볼 수 있는 예시 세 가지입니다. 앞의 두 행은 짧은 구간에 해당합니다. 세 번째 행은 입력 토큰이 28만 개이므로 요청 전체에 긴 구간을 적용합니다. 캐시 행은 사용량 기록이 해당 입력을 캐시 적중으로 집계했다고 가정합니다.

| 요청 | 계산 | 금액 |
| --- | --- | --- |
| 캐시되지 않은 입력 10만, 출력 5,000 | 0.1 × $2 + 0.005 × $6 | $0.23 |
| 캐시 읽기 10만, 출력 5,000 | 0.1 × $0.50 + 0.005 × $6 | $0.08 |
| 캐시되지 않은 입력 28만, 출력 10,000 | 0.28 × $4 + 0.01 × $12 | $1.24 |

이 28만 토큰에 짧은 구간 단가를 잘못 적용하면 0.28 × $2 + 0.01 × $6 = $0.62가 나오지만, 이는 이 구간의 가격이 아닙니다. Fast, 미국 리전 가산, 도구 호출 요금은 이 세 행에 반영하지 않았습니다.

### 가격표에 따로 적힌 배율

미국 리전 엔드포인트(`https://us.api.x.ai/v1`)는 추론을 미국 안에서 처리하며, 토큰 요금을 글로벌 가격의 1.1배, 즉 10% 가산해 청구합니다. 가격표에 적힌 `grok-4.7`의 결과는 200K 미만에서 입력 $2.20, 캐시 읽기 $0.55, 출력 $6.60이고, 200K 이상에서 입력 $4.40, 캐시 읽기 $1.10, 출력 $13.20입니다. 1.1배는 긴 구간을 포함해 입력, 출력, 캐시 읽기에 모두 적용됩니다. 캐시 할인을 먼저 적용한 뒤 1.1을 곱합니다.

Grok 4.7 Fast는 같은 모델을 더 빠른 인프라에서 제공하는 서비스입니다. 문서에 따르면 표준 요청은 2배, 긴 컨텍스트 요청은 1.5배이며, Cursor와 Grok Build에서만 제공되고 그쪽 요금제로 청구됩니다. 공개 xAI API에는 없으며 Grok Build의 무료 등급에도 포함되지 않습니다. 가격표에 적힌 Fast 단가는 200K 미만에서 입력 $4, 캐시 $1, 출력 $12, 200K 이상에서 입력 $6, 캐시 $1.50, 출력 $18입니다. $4 / $1 / $12는 짧은 구간의 2배입니다. $6 / $1.50 / $18은 긴 구간의 1.5배입니다. 발표 페이지에는 “출력 속도 2배, 가격 2배”라는 문장이 따로 있지만, 이 1.5배 구간은 적혀 있지 않습니다. 청구 금액은 문서의 이 표를 기준으로 계산하세요.

모델 페이지는 Batch API를 지원하지 않는다고 적고 있습니다. 가격표의 배치 할인 목록에는 `grok-4.7`이 없으며, 20% 배치 할인이 명시된 것은 다른 모델들입니다. 가격표는 텍스트 요청용 Priority Processing도 설명합니다. 응답에서 `service_tier`가 `priority`로 확인되면 2배로 청구되며, 캐시 할인을 먼저 적용한 뒤 곱합니다. Grok 4.7 모델 페이지에는 Priority 행이 따로 없습니다. 어떤 요청에 이 배율이 적용되었는지는 응답의 `service_tier`를 기준으로 판단합니다.

문서는 서버 측 도구의 호출 요금도 따로 적고 있습니다. 웹 검색은 호출 1,000회당 $5입니다. X 검색은 가져온 항목 수로 청구되며, 게시물 1,000건당 $5, 사용자 프로필 1,000건당 $10입니다. 코드 실행은 호출 1,000회당 $5입니다. 이 요금은 토큰 요금과 별도입니다. 모델 페이지에 적힌 속도 제한은 초당 150건 요청, 분당 50,000,000 토큰이며, 리전 표기는 `us-east-1`입니다. 문서는 팀별 현재 속도 제한과 실시간 가격은 모델 페이지를 기준으로 한다고 함께 밝히고 있으므로, 이 두 수치는 모든 계정에 대한 약속이 아닙니다.

## 발표 페이지의 벤치마크를 읽는 법

발표 페이지에 실린 것은 비교표이며, Folkbench의 측정이 아닙니다. 열은 Grok 4.7 xHigh, Grok 4.6 High, GPT-5.6 Sol Max, Fable 5.1 Max입니다. 가격 두 행은 그 페이지에 적힌 입력·출력 공식 가격입니다. DeepSWE의 `grok-4.7` 칸은 71.0%이며, 별표에는 이 칸이 열 머리글의 xHigh가 아니라 high로 측정되었다고 적혀 있습니다.

| 항목 | Grok 4.7 | Grok 4.6 | GPT-5.6 Sol | Fable 5.1 |
| --- | --- | --- | --- | --- |
| 입력 / 1M | $2 | $2 | $4 | $10 |
| 출력 / 1M | $6 | $6 | $20 | $50 |
| CursorBench 4.0 | 46.3% | 40.4% | 41.7% | 51.8% |
| DeepSWE v1.1 | 71.0%(high) | 65.2% | 72.7% | 70.0% |
| EEBench | 64.0% | 53.0% | 39.4% | 56.4% |
| AA Briefcase v1.1 | 1,657 | 1,546 | 1,487 | 1,678 |
| Terminal-Bench 4.0 | 37.6% | 20.3% | 37.3% | 57.9% |
| Harvey Legal Agent Benchmark | 19.6% | 15.8% | 2.5% | 6.7% |
| HealthBench Professional | 56.7% | 48.5% | 60.5% | 62.1% |

발표 페이지는 또한 Grok 4.7이 GDPval과 AA Briefcase 모두에서 Grok 4.6보다 앞서며, 다른 프런티어 모델과 비슷한 수준이라고 적고 있습니다. GDPval 차트는 본문에 옮겨 적을 수 있는 절대 점수를 제시하지 않으므로, 이 글은 숫자를 채워 넣지 않습니다. AA Briefcase 점수는 위 표의 1,657입니다.

안전 항목에는 두 가지 수치가 나옵니다. LatchBio의 생물 안전 벤치마크는 62.4%입니다. HackerBench v0.3에서는 위험한 이중 용도 프롬프트의 3.3%가 통과되었습니다. 페이지는 정당한 보안 작업을 차단하는 경우가 드물다고 적었지만, 정당한 요청의 거부율은 제시하지 않았습니다. 초청받은 사이버 보안 파트너는 초청 전용 레드팀 기능을 신청할 수 있습니다. 이 수치는 발표 페이지의 테스트를 설명하는 것이며, 일반 트래픽의 장애율이 아닙니다.

## 트래픽을 옮기기 전에 확인할 것

1. `grok-4.7`을 고정합니다. 완료 결과에 찍힌 모델명도 이 ID여야 합니다. 디렉터리 페이지는 `grok-4-7`을 사용합니다.
2. 기본 추론 강도는 `high`입니다. 비교할 때는 `low`, `medium`, `high`, `xhigh` 중 하나를 명시적으로 지정합니다.
3. 멀티턴 요청에는 `prompt_cache_key`를 붙이고, Chat Completions에서는 `x-grok-conv-id`를 붙입니다. Responses가 반환한 암호화된 reasoning은 그대로 다시 보냅니다.
4. 200K 미만 프롬프트와 200K에 도달한 프롬프트의 가격을 따로 계산합니다. 후자는 요청 전체에 긴 구간 단가를 적용합니다.
5. 미국 리전 엔드포인트는 1.1배로 청구됩니다. Fast는 공개 API에 없으므로 2배와 1.5배를 일반 API 청구액에 곱하지 마세요.
6. 모델 페이지는 Batch API를 지원하지 않는다고 적고 있습니다. 도구 호출에는 문서에 적힌 1,000회당 가격이 따로 붙습니다.
7. 발표 페이지 벤치마크 표의 경쟁 모델 열은 그 페이지에 적힌 가격과 점수를 그대로 따릅니다. DeepSWE의 71.0%는 xHigh가 아니라 high 기준입니다.
8. 중계 서비스가 이 ID를 제공하는지, 그리고 당시의 가용성과 실제 결제 가격은 디렉터리에 게시된 기록을 기준으로 합니다. 이 글의 표는 xAI 공식 가격이며, 특정 중계 서비스가 그룹 배율을 곱한 뒤의 사용자 가격이 아닙니다.
