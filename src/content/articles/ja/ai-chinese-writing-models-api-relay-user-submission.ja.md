コードが客観世界を精密にモデル化するものだとすれば、中国語の文章は「息づかい」と「温度」をめぐる、つかみどころのない技芸だと言えます。

アメリカ東海岸の深夜のアパートで、窓の外をときおり車が走り抜ける音を聞きながら、画面を流れていく文字の列を眺めています。ふとした瞬間に、数年前、復旦大学の学部生だった頃のことを思い出すことがあります。当時の私は、邯鄲路キャンパスの小さなカフェでノートを広げ、中国語の散文や読書ノートを一字一句練り上げるのが習慣でした。その後、海を渡ってアメリカの大学院に進み、英語一色の Academic Writing（アカデミック・ライティング）にすっかり染め上げられました。Thesis Statement（論点）や Topic Sentence（主題文）を徹底して重んじる、論理は緻密でもどこか冷たい西洋式の表現に、慣れざるを得なかったのです。

この「言語の二重生活」のおかげで、私は文字に対して極端に敏感になりました。英語の文章が求めるのは Clarity（明晰さ）と Precision（正確さ）で、論理の連鎖をはっきりとテーブルの上に並べる必要があります。一方、中国語の文章、とくに写意的な文章やノンフィクション、随筆で大切にされるのは、流れる水のような「気韻」と「言外の含み」です。

2023 年、誰もが ChatGPT で「まとめレポート」を書くことに夢中になっていたあの春から、2026 年の晩秋の今に至るまで、私が AI と付き合ってきた時間はまる 3 年になります。この 3 年間で、大規模言語モデルは、濃厚な「翻訳調」で「まず、次に、要するに」を連発していた理系の機械頭から一歩ずつ進化し、今では詩情を感じ取り、言葉の感覚を深められる文章の達人になりました。

2 つの言語のあいだを行き来する文章好きとして、また API をいじるのが好きな技術好きとして、無味乾燥な「指標の採点表」を作るつもりはありません。ここでは、2026 年の今、さまざまなモデルが私の実際の執筆の中で散らした spark（火花）と、API 中継サービスを使ってそれらを日々の執筆に取り込んできた実体験について、少しお話ししたいと思います。

## 1. 3 年にわたる中国語の語感の進化：「翻訳調」から「心の母語」へ

私と同じように GPT-3.5 の時代から使い続けてきた人なら、あの「AI っぽい中国語」に頭を抱えた経験があるはずです。

復旦にいた頃、90 年代の上海文学についての随筆を GPT-3.5 に推敲してもらおうとしたことがあります。すると、英語の Essay のテンプレートをそのまま当てはめ、もともと繊細だった情景をぎこちない三段論法に切り刻み、さらに「これは……であるだけでなく……でもあり、……を深く浮き彫りにしている」といった、生気のない決まり文句で文章を埋め尽くしてしまいました。まるで硬い英文法で中国語を無理やり翻訳したようなもので、母語の核心にある「意境」が失われていたのです。

そして 2026 年の今、GPT-6 と Claude Fable の登場によって、AI の中国語ライティングはついにこの壁を破りました。多くの場合、彼らはもはや「翻訳者」ではなく、向かいに座って言葉の組み合わせを一緒に検討してくれる書き手のような存在です。

## 2. 実際の執筆で起きたモデル同士のぶつかり合いと実例

この数年使ってきて、私はわざわざテスト問題を作ることはほとんどありません。むしろ文章を書いている最中に、同じ Prompt を気軽にいくつかのモデルに投げて、どの表現が心に刺さるかを見ています。

### 1. Claude Fable：「言葉にしにくい感情」をつかむ

復旦の学部時代、中国文学科の友人がよく「優れた文章は動詞で決まる」と言っていました。Fable の世代になると、文脈の中の感情の流れをとらえる力に、ときには少し「怖さ」すら感じます。最大の強みは AI 臭さがすっかり抜けていることで、1、2、3 と箇条書きにされることはほとんどありません。

たとえば先日、自分の随筆で、北米の大雨と、かつて江南で経験した梅雨の違いを描こうとしました。頭の中に感覚はあるのに、なかなか言葉が出てきません。そこで、ごく大ざっぱな指示を各モデルに送りました。「北米の豪雨が家を打つ様子と、江南の梅雨がしとしとと物を潤す様子の違いを対比する一文を、雰囲気たっぷりに書いて」

- **GPT-6 の文：**「北美的暴雨如倾盆而下，强烈地冲击着美式木屋的屋顶，展现出一种粗犷的气势；与此形成鲜明对比的是，江南的梅雨则是细密而绵长地洒落在小巷中，体现出一种含蓄的南方美感。」（訳：北米の豪雨は盆をひっくり返したように降り注ぎ、アメリカ式の木造家屋の屋根を強く打ちつけ、荒々しい勢いを見せる。これと鮮やかな対照をなすのが江南の梅雨で、細かく長く路地に降り注ぎ、控えめな南方の美しさを体現している）
- **Claude Fable の文：**「北美的雨是砸在美式木质窗框上的沉响，闷而空洞；江南的雨则是落入青砖缝隙里，连绵地往骨头深处渗。」（訳：北米の雨は、アメリカ式の木の窓枠に叩きつけられる重い音で、こもっていて虚ろだ。江南の雨は青い煉瓦の隙間に落ち、途切れることなく骨の奥へと染み込んでいく）

ご覧のとおり、GPT-6 はまだ「强烈（強く）」「鲜明对比（鮮やかな対照）」「体现出（体現している）」といった、説明文の定番の言葉を使っています。一方、Fable が「砸（叩きつける）」「沉响（重い音）」「往骨头深处渗（骨の奥へと染み込む）」という言葉を吐き出したとき、私の心は確かに震えました。選ばれた言葉には、音と手触りがあるのです。こうした「文学的な直感」は、海外のモデルの中ではまさに唯一無二です。今では、散文やノンフィクション、あるいはきわめて繊細な心理描写を書きたいときは、いつも Fable が第一の選択肢です。

### 2. GPT-6：「巨大で緻密な構造」を支えきる

Fable は叙情では無敵ですが、弱点もあります。長く書くと「散漫」になりやすいのです。強固な論理の骨格と膨大な知識の蓄えが必要なときには、GPT-6 の強みが発揮されます。

あるとき、芸術理論についての中国語の長い文章を書いていて、手元には雑然とした読書ノートしかありませんでした。そこで、そのまま各モデルに投げました。「フーコーの権力と言説、劉勰『文心雕龍』の『情采』、それに現代のネットミーム文化についての断片的なノートが 3 つある。これをつないで、深みのある学術エッセイの導入段落にして」

- **Fable の場合：** 語り口はとても優雅で叙情的で、書き出しからして「フーコーのまなざしが歴史の霧を貫くとき、千年前の劉勰が静かな深夜に漏らした長いため息が聞こえてくるかのようだ……」という調子でした。確かに美しいのですが、論理の連鎖はぼやけていて、3 つの概念は無理やりくっつけられているだけです。これではとても学術エッセイには使えません。
- **GPT-6 の場合：**「话语权力的生产机制不仅存在于现代制度的微观缝隙中（福柯语），同样折射于古典修辞学对‘情’与‘采’的辩证建构。当我们将这一视域延伸至当代的互联网梗文化时，会发现……」（訳：言説権力の生産メカニズムは、近代的制度の微細な隙間に存在するだけでなく（フーコーの言葉）、古典修辞学における「情」と「采」の弁証法的な構築にも同じように映し出されている。この視座を現代のネットミーム文化にまで広げると、……が見えてくる）

GPT-6 の文章は、まるで復旦の中国文学科のベテラン教授が書いたもののようです。骨格はきわめて堅く、文は整い、典故と概念が隙間なく織り合わされています。型破りなひらめきには少し欠けるものの、長編の構成づくり、複雑な理論の論評、本格的な科学解説となれば、その安定感は絶対的です。

### 3. 中国発の高性能モデル：「人情の機微」と本場の生活感がわかる

シリコンバレーのモデルがどれほど優秀でも、決して身につけられないものがあります。それは、中国社会の複雑な「言外の含み（Subtext）」と人情の機微です。

あるとき、小説の中で次のような会話を書こうとしました。舞台は南方の小さな町の路地裏。近所のおばさんが、表向きは隣の家の子どもの賢さを褒めながら、実は自分の子どものほうが成績がよかったことを、それとなく自慢している場面です。

- **GPT-6 と Fable の会話：**「张阿姨说：‘你的儿子真的很棒，考试得了高分，我真为你感到高兴。不过我的孩子这次也运气不错，拿到了第一名呢。’」（訳：張おばさんは言った。「あなたの息子さんは本当に素晴らしいわ。試験で高得点を取ったのね、私も心からうれしい。でも、うちの子も今回は運がよくて、1 位を取ったのよ」）まるで翻訳ドラマの台本を読んでいるようで、「ああ、友よ、今日の君は素敵だね」といった翻訳調に満ちています。中国人の話し方にある、あの遠回しな言い回しがまったくありません。
- **DeepSeek / 智譜の会話：**「张阿姨把择好的菜往盆里一扔，笑眯眯地说：‘哟，你家小明这次又考前三啦？真是不容易！不像我们家那个，天天就知道死读书，这次瞎猫打死耗子考了个第一，我都说他没啥好高兴的……’」（訳：張おばさんは下ごしらえを済ませた野菜をボウルにぽいと放り込み、にこにこしながら言った。「あら、小明くん、今回もまたトップ 3 なの？大したものねえ。うちのなんて毎日ガリ勉するしか能がなくて、今回はまぐれで 1 位を取っただけ。喜ぶようなことじゃないって言ってるのよ……」）

視線の駆け引き、言外の意味、そして本場の俗語や比喩。中国発のモデルは、国内向けのファインチューニングの後押しもあって、こうした部分を驚くほど正確につかんでいます。

## 3. ウェブ版の試行錯誤から中継サービスへ：自分の「執筆フロー」をどう組んだか

アメリカの大学院に来たばかりの頃は、さまざまなモデルを同時に使うために、あれこれと公式のサブスクリプションに課金していました。ところが使っているうちに、とてもつらいことに気づきました。**公式のウェブ版（Web UI）は「対話」のために設計されていて、「執筆」のために設計されたものではまったくない**のです。

ウェブ上で書いていると、タイプライターのように跳ねるカーソルが思考をひどく妨げます。さらに悪いことに、モデルごとに別々のブラウザータブに分かれています。骨格づくりには GPT-6 の論理が、推敲には Claude Fable の文章力が必要なのに、いくつものタブを行き来しているうちに、やっとの思いで高めた「執筆フロー（Flow State）」はとっくに消え去ってしまいます。

これが、私が API 中継サービスをいじり始めたきっかけです。ここからは、この 2 年間の試行錯誤をもとに、書き手の視点から見た中継サービスについての気づきを共有します。

### 1. 大事なのは「節約」ではなく、API をローカルのエディターにつなぐこと

中継サービスの話になると、多くの人はわずかな料金差ばかりを計算しています。しかし執筆の場面での中継サービスの最大の価値は、**世界トップクラスのモデルを一本化して、私がいちばん使い慣れたローカルの Markdown エディター（たとえば Obsidian）に組み込めること**にあります。

今の私にとっていちばん快適な執筆スタイルは、ブラウザーを一切開かないことです。ローカルのエディターで段落を選択し、そのままショートカットキーを押します。

- `Cmd+1` を押すと、中継サービスの API 経由で GPT-6 を呼び出し、段落のすぐ下に文章の構成案と論理の展開を生成します。
- 初稿を書き終えたら、叙情的な部分を選択して `Cmd+2` を押し、Claude Fable にその場で「脱 AI 化」の推敲をさせます。
- 地に足のついた会話が必要なところでは、`Cmd+3` を押して、中国発のモデルに表現を置き換えさせます。

中継サービスが発行する 1 つの API キーは、まるでエディターにパレットを差し込んだようなものです。絵の具を混ぜるように、さまざまなモデルの筆致を自在に呼び出せます。

### 2. 中継サービス選びにおける「執筆ならではの落とし穴」

コードを書くのと文章を書くのとでは、API 中継サービスに求めるものがまったく違います。この 2 年間、私もたくさんの落とし穴にはまりました。

- **コンテキストのひそかな圧縮に注意：** コストを節約するために、送信したコンテキストを裏側でこっそり切り詰める中継サービスがあります。コードを書くなら影響は小さいかもしれませんが、中国語の文章にとっては致命的です。中国語の「気韻」は、前の文脈で積み上げた感情にすべてかかっています。コンテキストが断ち切られた途端、Fable はたちまち普通の「翻訳調」に逆戻りしてしまいます。中継サービスを試すとき、私は 1,000 字を超える随筆を使って文脈のつながりを確かめるようにしています。モデルが前の文章の語調を引き継げなければ、その中継サービスはその時点で候補から外します。
- **温度パラメーター（Temperature）による「語感の調整」：** ウェブ版ではたいていパラメーターを変更できませんが、API で中継サービスにつなげば、Temperature の調整はまさに新しい世界への扉です。
  - **叙情的な散文・詩的な文章：** Claude Fable の `Temperature` を `0.8` 前後まで上げると、語彙の豊かさが爆発的に増し、あまり使われないけれど非常に美しい言葉をよく繰り出してくれます。
  - **論理的な論述・構成づくり：** GPT-6 の `Temperature` を `0.2` まで下げると、GPT-6 は冷静な哲学者のようになり、出力される論理の連鎖はきわめて安定し、無駄なことは一切言いません。

## おわりに

2026 年の今から振り返ると、AI は当初みんなが心配したように「文章を殺す」ことはありませんでした。

北米の深夜、デスクライトの下で、私は今も AI が生成した無数の文の中から、この瞬間の心境にいちばんしっくりくる中国語の一文を丹念に選び出すのが好きです。GPT-6 は深い構造を、Claude Fable は優しい共鳴を与えてくれます。そして中継サービスは目に見えない執事のように、こうした知恵袋たちを、音もなく私のペン先の下に配してくれるのです。

それらを呼び出し、その気性を理解することを学ぶのは、実は私たち自身が中国語とどう向き合うかを見つめ直すことでもあります。最終的に言葉をどこに置くかを決めるのは、いつだって画面の前にいる血の通った自分自身です。江南の梅雨と、光華楼を吹き抜ける風の音を懐かしむ、この私なのです。
