> 以下の仕様と価格は xAI のドキュメントと価格表から、ベンチマークは 2026 年 9 月 21 日の発表ページから取ったもので、確認日は 2026 年 10 月 2 日です。Folkbench はこれらの評価を再実行していません。発表ページにある競合モデルの価格とスコアは、そのページに掲載された数値であり、同じ日に OpenAI や Anthropic の価格表と照合し直したものではありません。

xAI は 2026 年 9 月 21 日に Grok 4.7 を発表しました。API のモデル名は `grok-4.7` です。ドキュメントでは、コーディング、エージェントタスク、ナレッジワーク向けのフロンティアモデルと説明されています。発表ページの本文には、[Grok 4.6](https://x.ai/news/grok-4-6) と同じ価格・同じ速度で提供すると書かれています。一方、同じページの見出しには「約 2 倍の速度、同クラスのモデルの約半分の価格」とあります。どちらの文も発表ページに載っていますが、本記事では見出しの文を新たな価格表としては扱いません。

同じ日に照合できる箇所は、主に 3 つあります。ドキュメントの概要表には、500,000 トークンのコンテキスト、2026 年 5 月の知識のカットオフ、短コンテキストの入力 $2・出力 $6 が載っています。価格表では、プロンプトが 200K トークンに達すると長コンテキストの価格に切り替わり、リクエスト全体がその価格で計算されます。発表ページのベンチマーク表は、`grok-4.7` を Grok 4.6、GPT-5.6 Sol、Fable 5.1 と並べています。OpenAI 側の長コンテキストの価格区分は [GPT-6.1 Sol](https://folkbench.com/ja/blog/gpt-6-1-sol-review-pricing) を、Claude 側は [Opus 5.5](https://folkbench.com/ja/blog/claude-opus-5-5-review-pricing) と [Sonnet 5.5](https://folkbench.com/ja/blog/claude-sonnet-5-5-review-pricing) を参照してください。

## 公開済みの仕様

| 項目 | Grok 4.7 |
| --- | --- |
| モデル名 | `grok-4.7` |
| 発表日 | 2026 年 9 月 21 日 |
| コンテキストウィンドウ | 500,000 トークン |
| 知識のカットオフ | 2026 年 5 月 |
| 入力と出力 | テキストと画像を入力し、テキストを出力 |
| 概要表の出力上限 | テキスト出力の上限なしと記載。最大出力トークン数は別途記載なし |
| `reasoning` | `low`、`medium`、`high`（デフォルト）、`xhigh` |
| API | Responses、Chat Completions |
| ドキュメントに記載のツール | 関数呼び出し、ウェブ検索、X 検索、コード実行 |
| モデルページ上の Batch API | 非対応 |

モデルページでは、デフォルトの effort は `high` です。ドキュメントは、Responses では `prompt_cache_key` を、Chat Completions ではリクエストヘッダー `x-grok-conv-id` を設定するよう勧めています。ページによると、このキーがないと会話のリクエストはまだキャッシュのないサーバーに振り分けられることが多く、入力はキャッシュなしの価格で課金されます。Responses は、リクエストの `include` に指定していなくても `reasoning.encrypted_content` を返します。マルチターンの会話では、これらの reasoning 項目をそのまま次の `input` に戻す必要があります。ドキュメントには、Chat Completions のこの点は変更されていないと書かれています。

ドキュメントに記載されている利用先は、xAI API、米国リージョンのエンドポイント `https://us.api.x.ai/v1`、Grok Build、Cursor、そして OpenRouter、Vercel、Cloudflare です。Grok Build のデフォルトモデルはこのモデルです。米国リージョンのエンドポイントで現在記載されているモデルは `grok-4.7` と `grok-4.6` です。特定の中継サービスがこの ID を提供しているかどうかは、ディレクトリで公開済みの記録に従ってください。

## 公式価格

### 短コンテキストと長コンテキスト

単位は 100 万トークンあたりの米ドルです。短コンテキスト区分（以下、短区分）と長コンテキスト区分（以下、長区分）は、どちらも 2026 年 10 月 2 日に確認した API 価格表から取りました。価格表によると、長コンテキストのしきい値はプロンプト 200K トークンです。これに達すると、そのリクエストのすべてのトークンが長区分の単価で計算されます。超過分だけが割増になるわけではありません。この表では、`grok-4.7` と `grok-4.6` の 6 つのセルはすべて同じ値です。

| 100 万トークンあたり | 4.7 短 | 4.7 長 | 4.6 短 | 4.6 長 |
| --- | --- | --- | --- | --- |
| 入力 | $2 | $4 | $2 | $4 |
| キャッシュ読み取り | $0.50 | $1 | $0.50 | $1 |
| 出力 | $6 | $12 | $6 | $12 |

200K 未満のプロンプトには短区分が適用されます。200K に達したリクエストでは、それ以前のトークンも長区分の単価で計算されます。長区分は短区分の 2 倍で、$2 × 2 = $4、キャッシュは $0.50 × 2 = $1、出力は $6 × 2 = $12 です。キャッシュ読み取りは同じ区分の入力価格の 4 分の 1 で、$2 × 0.25 = $0.50、$4 × 0.25 = $1 です。

標準区分で手計算できる例を 3 つ挙げます。最初の 2 行は短区分に収まります。3 行目は入力トークンが 28 万なので、リクエスト全体が長区分になります。キャッシュの行は、使用量の記録でこれらの入力がキャッシュヒットとして計上されることを前提としています。

| リクエスト | 計算 | 金額 |
| --- | --- | --- |
| キャッシュなし入力 10 万、出力 5,000 | 0.1 × $2 + 0.005 × $6 | $0.23 |
| キャッシュ読み取り 10 万、出力 5,000 | 0.1 × $0.50 + 0.005 × $6 | $0.08 |
| キャッシュなし入力 28 万、出力 10,000 | 0.28 × $4 + 0.01 × $12 | $1.24 |

この 28 万トークンに誤って短区分の単価を掛けると 0.28 × $2 + 0.01 × $6 = $0.62 になりますが、これはこの区分の価格ではありません。この 3 行には、Fast、米国リージョンの割増、ツール呼び出しはまだ反映していません。

### 価格表に別途記載された倍率

米国リージョンのエンドポイント `https://us.api.x.ai/v1` は推論を米国内で行い、トークンはグローバル価格の 1.1 倍、つまり 10% 増しで課金されます。価格表に記載された `grok-4.7` の結果は、200K 未満が入力 $2.20、キャッシュ読み取り $0.55、出力 $6.60、200K 以上が入力 $4.40、キャッシュ読み取り $1.10、出力 $13.20 です。1.1 倍は入力、出力、キャッシュ読み取りに適用され、長区分も含みます。キャッシュ割引を先に計算し、そのあとに 1.1 倍を掛けます。

Grok 4.7 Fast は、同じモデルをより高速なインフラで提供するものです。ドキュメントによると、標準リクエストは 2 倍、長コンテキストのリクエストは 1.5 倍です。提供先は Cursor と Grok Build だけで、それぞれのプランで課金されます。公開の xAI API にはなく、Grok Build の無料プランにも含まれません。価格表に記載された Fast の単価は、200K 未満が入力 $4、キャッシュ $1、出力 $12、200K 以上が入力 $6、キャッシュ $1.50、出力 $18 です。$4 / $1 / $12 は短区分の 2 倍、$6 / $1.50 / $18 は長区分の 1.5 倍です。発表ページには「出力速度 2 倍、価格 2 倍」という一文もありますが、この 1.5 倍の区分は書かれていません。課金にはドキュメントのこの表を使ってください。

モデルページには、Batch API は非対応と書かれています。価格表のバッチ割引の対象リストに `grok-4.7` はなく、20% のバッチ割引が明記されているのは別のモデル群です。価格表には、テキストリクエスト向けの Priority Processing も説明されています。レスポンスで `service_tier` が `priority` と確認された場合は 2 倍で課金され、キャッシュ割引を先に計算してから倍率を掛けます。Grok 4.7 のモデルページには、Priority の行は別途ありません。あるリクエストにこの倍率が適用されたかどうかは、レスポンスの `service_tier` で確認してください。

ドキュメントには、サーバー側ツールの呼び出し価格も別に記載されています。ウェブ検索は 1,000 回の呼び出しあたり $5 です。X 検索は取得した件数で課金され、投稿 1,000 件あたり $5、ユーザープロフィール 1,000 件あたり $10 です。コード実行は 1,000 回の呼び出しあたり $5 です。これらの料金はトークン料金とは別にかかります。モデルページに記載されたレート制限は毎秒 150 リクエスト、毎分 50,000,000 トークンで、リージョンは `us-east-1` です。ドキュメントは同時に、チームごとのその時点のレート制限とリアルタイムの価格はモデルページに従うとしています。そのため、この 2 つの数値はすべてのアカウントに対する約束ではありません。

## 発表ページのベンチマークの読み方

発表ページに掲載されているのは比較表であり、Folkbench の計測ではありません。列は Grok 4.7 xHigh、Grok 4.6 High、GPT-5.6 Sol Max、Fable 5.1 Max です。価格の 2 行は、そのページに掲載された入力と出力の公式価格です。DeepSWE の `grok-4.7` のセルは 71.0% で、アスタリスクの注記によると、このセルは列見出しの xHigh ではなく high で計測されています。

| 項目 | Grok 4.7 | Grok 4.6 | GPT-5.6 Sol | Fable 5.1 |
| --- | --- | --- | --- | --- |
| 入力 / 100 万 | $2 | $2 | $4 | $10 |
| 出力 / 100 万 | $6 | $6 | $20 | $50 |
| CursorBench 4.0 | 46.3% | 40.4% | 41.7% | 51.8% |
| DeepSWE v1.1 | 71.0%（high） | 65.2% | 72.7% | 70.0% |
| EEBench | 64.0% | 53.0% | 39.4% | 56.4% |
| AA Briefcase v1.1 | 1,657 | 1,546 | 1,487 | 1,678 |
| Terminal-Bench 4.0 | 37.6% | 20.3% | 37.3% | 57.9% |
| Harvey Legal Agent Benchmark | 19.6% | 15.8% | 2.5% | 6.7% |
| HealthBench Professional | 56.7% | 48.5% | 60.5% | 62.1% |

発表ページには、Grok 4.7 は GDPval と AA Briefcase のどちらでも Grok 4.6 を上回り、ほかのフロンティアモデルと同等だとも書かれています。GDPval のグラフについては、本文に書き写せる絶対スコアが示されていないため、本記事でも数値は補っていません。AA Briefcase のスコアは、上の表にある 1,657 です。

安全性のセクションには、数値が 2 つ載っています。LatchBio のバイオセーフティベンチマークは 62.4% です。HackerBench v0.3 では、リスクのあるデュアルユースのプロンプトが通過した割合は 3.3% でした。ページには正当なセキュリティ業務がブロックされることはまれだと書かれていますが、正当なリクエストの拒否率は示されていません。招待されたサイバーセキュリティのパートナーは、招待制のレッドチーム機能を申請できます。これらの数値は発表ページのテストに関する記述であり、通常のトラフィックでの障害率ではありません。

## トラフィックを切り替える前の確認事項

1. `grok-4.7` を固定します。完了結果のモデル名もこの ID である必要があります。ディレクトリのページでは `grok-4-7` を使っています。
2. デフォルトの effort は `high` です。比較するときは、`low`、`medium`、`high`、`xhigh` を明示的に指定します。
3. マルチターンのリクエストには `prompt_cache_key` を付けるか、Chat Completions では `x-grok-conv-id` を付けます。Responses が返す暗号化された reasoning は、そのまま送り返します。
4. 200K 未満のプロンプトと 200K に達するプロンプトを、それぞれ別に見積もります。後者はリクエスト全体に長区分の単価が適用されます。
5. 米国リージョンのエンドポイントは 1.1 倍で課金されます。Fast は公開 API にはないため、2 倍や 1.5 倍を通常の API の請求に掛けないでください。
6. モデルページには、Batch API は非対応と書かれています。ツール呼び出しは、ドキュメントにある 1,000 回あたりの価格で別に加算します。
7. 発表ページのベンチマーク表にある競合モデルの列は、そのページに掲載された価格とスコアのまま扱います。DeepSWE の 71.0% は high での値で、xHigh ではありません。
8. 中継サービスがこの ID を提供しているかどうか、またその時点の稼働率と実際の請求価格は、ディレクトリで公開済みの記録に従ってください。本記事の表は xAI の公式価格であり、特定の中継サービスが倍率を掛けたあとの利用者向け価格ではありません。
