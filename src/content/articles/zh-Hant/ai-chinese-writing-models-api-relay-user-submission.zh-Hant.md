如果說程式碼是對客觀世界的精細建模，那麼中文寫作絕對是一門關於「氣息」與「溫度」的玄學。

坐在美國東岸深夜的公寓裡，窗外偶爾傳來車流聲，螢幕上是一行行正在流淌的文字。我常常會在某個瞬間恍神，想起幾年前在復旦念大學的日子。那時我習慣待在邯鄲路校區的小咖啡館裡，拿著筆記本一字一句地琢磨中文散文和讀書筆記。後來遠渡重洋到美國念研究所，開始被全英文的 Academic Writing（學術寫作）洗腦——被迫習慣那種極度強調 Thesis Statement（論點）、Topic Sentence（主題句）、邏輯嚴密卻有些冰冷的西式表達。

這種「語言的雙重生活」讓我對文字變得極度敏感。英文寫作追求的是 Clarity（清晰）與 Precision（精準），需要把邏輯鏈條明明白白地攤在桌面上；而中文寫作，尤其是寫意、非虛構或隨筆，講究的是如流水般的「氣韻」與「言外之意」。

從 2023 年那個大家都沉迷於用 ChatGPT 寫「總結報告」的春天開始，到如今 2026 年的深秋，我和 AI 打交道已經整整三年了。這三年裡，我眼看著大型模型從最初那個說話帶著濃重「翻譯腔」、滿口「首先、其次、總之」的理工科機械腦，一步步進化成今天能夠體會詩意、沉澱語感的文字高手。

身為一個穿梭在兩種語言之間的文字愛好者，也是一個喜歡動手玩 API 的技術愛好者，我不想做那種乾巴巴的「指標評分表」。這裡只想聊聊在 2026 年的今天，不同模型在我實際寫作中擦出的 spark，以及我用 API 中轉站把它們融入日常寫作的一些真實體驗。

## 一、橫跨三年的中文語感演進：從「翻譯腔」到「精神母語」

如果您跟我一樣，是從 GPT-3.5 時代一路用過來的，一定對那種「AI 風格的中文」痛心疾首。

在復旦的時候，我曾試著用 GPT-3.5 幫我潤飾一篇談九〇年代上海文學的隨筆，結果它直接套用一套英文 Essay 的範本，把原本細膩的情景切割成生硬的三段論，文中還充斥著「這不僅……而且……，深刻地揭示了……」這種毫無靈氣的制式套話。那種感覺，就像是用生硬的英文文法強行翻譯中文，丟掉了母語最核心的「意境」。

到了 2026 年的今天，隨著 GPT-6 與 Claude Fable 問世，AI 在中文寫作上的表現終於打破了這道屏障。很多時候，它們不再是一個「翻譯官」，而更像是坐在對面、跟您推敲字詞搭配的寫作者。

## 二、我在真實寫作中的模型碰撞與例子

這幾年用下來，我其實很少特地出測驗題給它們，更多是在寫東西的時候，順手把同一個 Prompt 丟給不同的模型，看看誰的表達能打中我。

### 1. Claude Fable：抓得住那些「說不出口的情緒」

在復旦念大學時，中文系的朋友常說：「上等的文字，動詞定乾坤。」到了 Fable 這一代，它對上下文情感流動的捕捉，有時甚至讓我覺得有點「可怕」。它最厲害的地方在於洗淨了 AI 味，幾乎不會給您列出 1、2、3。

例如前陣子我自己寫隨筆，想描寫北美這邊下大雨和以前在江南下梅雨的差別。腦子裡有那種感覺，卻一時卡住寫不出來，我就丟給它們一句很粗糙的話：「幫我寫一句話，比較一下北美的暴雨打在房子上，和江南梅雨那種潤物細無聲的差別，要有氛圍感。」

- **GPT-6 給我的句子：**「北美的暴雨如傾盆而下，強烈地衝擊著美式木屋的屋頂，展現出一種粗獷的氣勢；與此形成鮮明對比的是，江南的梅雨則是細密而綿長地灑落在小巷中，體現出一種含蓄的南方美感。」
- **Claude Fable 給我的句子：**「北美的雨是砸在美式木質窗框上的沉響，悶而空洞；江南的雨則是落入青磚縫隙裡，連綿地往骨頭深處滲。」

您看，GPT-6 還在用「強烈」「鮮明對比」「體現出」這種標準的說明文詞彙；而 Fable 吐出「砸」「沉響」「往骨頭深處滲」這幾個字的時候，我心裡確實震了一下。它挑選的字詞帶有聲音和觸感，這種「文學直覺」在海外模型裡簡直是獨一份。現在只要我想寫散文、非虛構，或是需要極其細膩的心理描寫，Fable 永遠是我的第一選擇。

### 2. GPT-6：撐得起「龐大而嚴密的宏大結構」

雖然 Fable 在抒情上無敵，但它也有短處——寫長了容易「散」。當需要極強的邏輯骨架和龐大的知識儲備時，GPT-6 的優勢就出來了。

有一次我在寫一篇談藝術理論的中文長文，手上只有一堆亂七八糟的讀書筆記，我直接丟給它們：「我這裡有關於傅柯的權力話語、劉勰《文心雕龍》裡的『情采』，還有現代網路迷因文化的三份零碎筆記，幫我串成一段有深度的學術隨筆導言。」

- **Fable 寫出來是這樣：** 它的語氣非常優雅抒情，一開口就是「當福柯的目光穿透歷史的迷霧，我們彷彿能聽見千年前劉勰在寂靜深夜裡的長嘆……」寫得確實美，但邏輯鏈條是糊的，三個概念只是硬湊在一起，根本放不進學術隨筆裡。
- **GPT-6 寫出來則是這樣：**「話語權力的生產機制不僅存在於現代制度的微觀縫隙中（福柯語），同樣折射於古典修辭學對『情』與『采』的辯證建構。當我們將這一視域延伸至當代的互聯網梗文化時，會發現……」

GPT-6 就像復旦中文系老教授寫的東西——骨架極硬，造句工整，典故和概念交織得嚴絲合縫。雖然少了點劍走偏鋒的靈氣，但要論搭建長篇文章大綱、複雜的理論評述或硬派科普，它的穩定性無可挑剔。

### 3. 中國本土高階模型：懂「人情世故」與道地的煙火氣

矽谷模型再厲害，有一點它們永遠學不會，那就是中國社會複雜的「潛台詞（Subtext）」和人情世故。

有一次我想在小說裡寫一段對話，背景是南方小鎮的弄堂，鄰居阿姨表面上在誇隔壁家的小孩聰明，實際上是在暗地裡炫耀自己家孩子考得更好。

- **GPT-6 和 Fable 寫出來的對話：**「張阿姨說：『你的兒子真的很棒，考試得了高分，我真為你感到高興。不過我的孩子這次也運氣不錯，拿到了第一名呢。』」這聽起來就像在讀翻譯劇本，充滿一種「喔，我的朋友，你今天看起來真不錯」的翻譯腔，完全沒有中國人說話時那種拐彎抹角。
- **DeepSeek / 智譜寫出來的對話：**「張阿姨把擇好的菜往盆裡一扔，笑瞇瞇地說：『喲，你家小明這次又考前三啦？真是不容易！不像我們家那個，天天就知道死讀書，這次瞎貓打死耗子考了個第一，我都說他沒啥好高興的……』」

那種眼神的拉扯、言外之意，以及道地的俚語隱喻，中國本土模型有在地化微調加持，拿捏得極其精準。

## 三、從網頁版到中轉站：我如何打造自己的「寫作流」

剛到美國念研究所時，為了能同時用上各種模型，我付費訂閱了好幾家官方服務。但用著用著，我發現了一件非常痛苦的事：**官方網頁（Web UI）是為「對話」設計的，根本不是為「寫作」設計的。**

在網頁裡寫作，游標像打字機一樣跳動，會嚴重打斷思緒；更糟的是，不同模型分散在不同的瀏覽器分頁裡。我需要 GPT-6 的邏輯來搭骨架，又需要 Claude Fable 的文筆來潤飾，在幾個 tab 之間切來切去，好不容易累積出來的一點「寫作流（Flow State）」早就散光了。

這就是我開始研究 API 中轉站的起點。接下來，想結合這兩年的摸索經驗，分享一些寫作者視角的中轉站心得：

### 1. 重點不是「省錢」，而是把 API 接進本機編輯器

很多人聊中轉站，總是在計較幾分幾厘，但在寫作情境下，中轉站最大的價值在於**把全球頂尖模型統一串起來，接進我最順手的本機 Markdown 編輯器（例如 Obsidian）**。

我現在最舒服的寫作狀態是：不必開任何瀏覽器。在本機編輯器裡選取段落，直接按快速鍵：

- 按下 `Cmd+1`，透過中轉站 API 呼叫 GPT-6，在段落下方直接生成文章大綱和邏輯推演；
- 寫完初稿後，選取抒情的部分按下 `Cmd+2`，呼叫 Claude Fable 直接在原處做「去 AI 化」潤飾；
- 遇到需要道地口吻的對話，按 `Cmd+3` 用中國本土模型替換表達。

中轉站給的一組 API 金鑰，就像為我的編輯器插上一塊調色盤，讓我可以像調配顏料一樣，隨手運用不同模型的筆觸。

### 2. 挑選中轉站時的「寫作地雷」

寫程式和寫文章對 API 中轉站的要求完全不同，這兩年我也踩過不少雷：

- **小心上下文被暗中壓縮：** 有些中轉站為了省成本，會在背景偷偷裁剪您送出的上下文。寫程式也許影響不大，但對中文寫作來說是場災難！中文的「氣韻」全靠前文的情感鋪陳，一旦上下文被切斷，Fable 就會立刻退化回普通的「翻譯腔」。測試中轉站時，我習慣用一篇上千字的隨筆來測它的上下文連貫性，如果模型接不上前文的語氣，這家中轉站就可以直接 pass 了。
- **溫度參數（Temperature）的「語感調校」：** 網頁版通常不能改參數，但透過 API 接上中轉站之後，調整 Temperature 簡直像打開了新世界的大門：
  - **抒情散文/詩意文字：** 把 Claude Fable 的 `Temperature` 調高到 `0.8` 左右，用詞的豐富度會爆炸性成長，常常冒出一些冷門卻極具美感的詞彙。
  - **邏輯論述/搭建大綱：** 把 GPT-6 的 `Temperature` 壓低到 `0.2`，這時的 GPT-6 就像一位冷靜的哲學家，輸出的邏輯鏈極度穩定，絕不說廢話。

## 寫在最後

站在 2026 年的今天回頭看，AI 並沒有像大家最初擔心的那樣「殺死寫作」。

在北美深夜的檯燈下，我依然喜歡從 AI 生成的無數段落中，仔細挑出那一句最貼合我此時此刻心境的中文。GPT-6 給了我深刻的結構，Claude Fable 給了我溫柔的共鳴，而中轉站就像一位無形的管家，把這些智囊悄無聲息地安插在我的筆尖之下。

學會運用它們、摸清它們的脾性，其實也是在重新審視我們自己對待中文的態度。最終決定文字要落在哪裡的，永遠是螢幕前那個有血有肉、懷念著江南梅雨與光華樓風聲的自己。
