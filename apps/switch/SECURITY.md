# Folkbench Switch 安全政策

客户端安全边界、报告渠道和发布门禁以仓库根目录的 [SECURITY.md](https://github.com/Folkbench/folkbench/blob/main/SECURITY.md) 为准。

首版 Beta 将先提供未公证的 macOS 安装包，Windows 包暂未提供数字签名。具体签名状态和校验文件以本仓库 Release 为准。

不在公开 Issue 中提交 Key、登录令牌、私钥、提示词、完整配置或未脱敏日志。

## 可选客户端使用统计

使用统计默认关闭，只有用户在设置中明确启用后才发送。仅包含版本、平台、随机安装/会话标识及预设操作结果，不包含 Key、密码、聊天内容、项目路径、自定义 API 地址、账号身份或本地 Token/费用明细。

本地队列最多保留 1,000 条、7 天；关闭统计会清空待上报记录与安装标识。上报失败不阻塞客户端功能。既有更新公钥与固定更新源保持不变，安装后的版本确认只在新进程实际运行目标版本时产生。
